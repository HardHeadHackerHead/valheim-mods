0.1.1: Fix: only the first kill in a minute reached the scripts (every creature's id was lost by the time its death was handled, so the next kills looked like repeats of the first). Kill events (Infinite Boars, The Wild Hunt's counting, Kill Streaks) fire for every kill again. New Claude Tools commands for the server's owner: blockscript players and blockscript admin NAME [on|off]. The time of day can now be set three times at once, then once every 20 seconds (Meteor Shower's morning was refused). The window's default key is Home.
0.1.0: First release. A block editor for scripts (Home, or the console command blockscript): 215 blocks in 11 tabs with search, zoom, tidy up, collapse, undo, a code page and a log page, plus typed JavaScript for people who prefer it. Waits, signals, lists, loops, your own blocks, math and text. Events for kills, deaths, joins, chat, bosses, day and night, pickups, eating, building, hits, raids, weather, respawns, chat commands and taming; actions for messages, banners, speech bubbles, map pings, items, spawning, decorations, weather, wind, time, lightning and other effects, status effects, healing and hurting, raids and web hooks. Every power is asked for in plain words, with limits the world's owner sets in the settings; a script is refused (and the log and the screen say which limit) rather than crashing. Eight example scripts, including The Wild Hunt, Meteor Shower and Treasure Hunt. Runs on the server; players who have the mod get items, healing and effects on their own game, admins edit the server's scripts from their own game and can edit one script together, live. A Blockscript program on Quad's Terminal. Not yet tried between two real games (multiplayer and live co-editing are built and tested without the game), and English only for now.
