0.1.6: New events for trees: treeFelled (a tree comes down) and logBroken (a fallen log breaks), with the kind of tree (beech, birch, fir, oak, pine, ancient, yggdrasil), the wood it gives, whether the log split into smaller logs, where, and who did it; blocks "when a tree falls" and "when a log breaks" with what they tell. They work for every player: a player's game reports the trees it owns. New example: Fine Wood from logs (ordinary logs drop two Fine Wood as well when they break into wood). New setting: Items given per hour per script (it was always 50). The heal and hurt blocks no longer stop a script when given something that is not a player or creature.
0.1.5: pieceBuilt for pieces other players build (their message arrives before the piece does: the server now waits up to five seconds for it). playerLeave says who left (the name was always empty). Checked with two players: pickups, building, hits, kills, eating and chat from another player's game all reach the scripts.
0.1.4: Important fix. Some effects (lightning, the mead effects and others) were made as world objects, and each left an empty world record behind when it ended; the game then waits for those objects forever, so a respawn or a teleport near one never finishes. Effects are now made on each screen with no world record, and the server removes any such leftovers when a world loads and every ten minutes (the log says how many). Claude Tools: blockscript sweep.
0.1.3: Players' games now report what only they see (picking things up, building, hits, eating, skill-ups, taming): the hooks for these were only switched on on the server, so a player's game had nothing to forward. The server's log says once when it turns down an event a player's game sent, and why.
0.1.2: Fixes from the first two-player test. A script's teleport could leave the player under the game's black teleport screen for good (the game's short teleport waits for a floor it may never find): short moves now place the player on the ground directly, long ones end after 25 seconds whatever happens, and landing never counts as a fall. Actions on other players (give, heal, effects...) were refused as if their game lacked the mod, because the connection was recorded before the game knew the player's id: it is now kept up to date. After the server's mod reloads it asks players' games to greet it again. Rested and other player-only effects are refused on creatures instead of failing inside the game.
0.1.1: Fix: only the first kill in a minute reached the scripts (every creature's id was lost by the time its death was handled, so the next kills looked like repeats of the first). Kill events (Infinite Boars, The Wild Hunt's counting, Kill Streaks) fire for every kill again. New Claude Tools commands for the server's owner: blockscript players and blockscript admin NAME [on|off]. The time of day can now be set three times at once, then once every 20 seconds (Meteor Shower's morning was refused). The window's default key is Home.
0.1.0: First release. A block editor for scripts (Home, or the console command blockscript): 215 blocks in 11 tabs with search, zoom, tidy up, collapse, undo, a code page and a log page, plus typed JavaScript for people who prefer it. Waits, signals, lists, loops, your own blocks, math and text. Events for kills, deaths, joins, chat, bosses, day and night, pickups, eating, building, hits, raids, weather, respawns, chat commands and taming; actions for messages, banners, speech bubbles, map pings, items, spawning, decorations, weather, wind, time, lightning and other effects, status effects, healing and hurting, raids and web hooks. Every power is asked for in plain words, with limits the world's owner sets in the settings; a script is refused (and the log and the screen say which limit) rather than crashing. Eight example scripts, including The Wild Hunt, Meteor Shower and Treasure Hunt. Runs on the server; players who have the mod get items, healing and effects on their own game, admins edit the server's scripts from their own game and can edit one script together, live. A Blockscript program on Quad's Terminal. Not yet tried between two real games (multiplayer and live co-editing are built and tested without the game), and English only for now.
