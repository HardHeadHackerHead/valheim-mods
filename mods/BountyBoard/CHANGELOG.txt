1.4.4: On a server without Bounty Board, the bounty board is gone from the hammer, and a message says why: the server would delete a board built there. Server owners can change what a bounty board costs ("Building", Cost; today's cost, 20 wood, 6 leather scraps and 4 flint, is the default); in multiplayer the server's cost applies, and a cost with a mistake in it keeps the last good one. Settings: edits to the config file now apply while the game runs (a server owner no longer has to restart), and a server's admins can change the server's settings from their own game with Configuration Manager, where other players see them greyed out. Your config file always keeps your own values while you play on a server (saving it there could write the server's in). Players on an older version still get the server's settings. It's no longer counted as storage in the game's own building records (it was copied from a chest). It snaps by the corners of its base now (to floor corners, wall ends and other boards); hold the alt-place key (Shift) to place it freely.

1.4.3: Its windows no longer fill the log with "The LiberationSans SDF Font Asset was not found": each text is given the game's font before it starts (it looked for TextMeshPro's default font, which the game doesn't have, every time a text was made). Nothing changes on screen.

1.4.2: Its build piece now also clears destroyed pieces left in the hammer's list by other mods when it registers: after a mod is reloaded at the main menu, a leftover one made every change to your bag throw an error half-way (crafting gave the item without taking the cost) until the game was restarted.

1.4.1: Less network traffic in multiplayer: a kill that counts for a contract now sends the board to everyone at most once a second, not with every kill (a sweep in a big fight sent the whole board several times a second). The player who made the kill still sees their progress at once, and a finished contract goes out straight away. Older versions on the same server keep working.

1.4.0: Now in your language: English, Russian, German, Chinese (Simplified), Portuguese (Brazil), Spanish, French, Polish and Turkish, following the game's own Language setting. The game's own names are used for its things (items, creatures, lands, stations). The translations were made with AI: to correct a line, or add a language, put a file in BepInEx/config/translations/com.quad.bountyboard/ named after the game's name for the language (German.json...) with only the lines you change, copied from translations/English.json on GitHub. Contracts are written on each player's screen in their own language (the saved contracts are unchanged). Players on a server should update together: a player on an older version gets no contract messages from a newer host. The reward uses the game's word for Coins.

1.3.1: Tab no longer opens your inventory under the board's menu (it closes the menu, as it closes a chest), and the chat and map keys stay quiet while it's open.

1.3.0: The board's menu and the contracts on your screen are now part of the game's look: the crafting screen's wood panel, title and tabs, each contract on its own card with its trophy, the reward in the inventory's own cells (with their tooltips) and the group's progress as a bar, the game's own buttons; the contracts on your screen sit in the HUD and hide with it. E closes the menu again, as it does a chest.

1.2.2: A clearer page: what it does, who needs it in multiplayer, how it gets on with other mods, and where to report a bug. The game itself is unchanged.

1.2.1: A new id, com.quad.bountyboard (it was com.dhack.bountyboard): your settings move over by themselves the first time it starts, and the old settings file is kept as a backup. Restart the game after this update. If an old copy is still installed beside it, this one stands down and says which file to delete, so the two never both run. The DLL now says it was made with AI, as Thunderstore asks.

1.2.0: Fix: a finished contract's reward could be collected again and again with new characters. The host now goes by who is actually playing on each connection (not what the message says) and pays only the characters that worked on a contract (took it, made a kill for it or handed loot in) or were playing when it was finished. (Contracts finished before this update can still be collected as before.) In multiplayer the host's notice and contract settings now apply on everyone's screen too. The menu and tracker use the game's fonts, and a problem drawing the board's look can no longer stop it being registered.

Fix: after a fresh game start the board was not registered until the mods were reloaded, so the game deleted any it found standing in the world. It is now registered as the world loads. Ones already lost can't be brought back; build them again. Fix: kills by any player now count in multiplayer (before, a kill only counted when the killer's own game was handling that creature). Fix: hosting a different world without restarting the game no longer carries the last world's contracts over and overwrites the new one's. Contracts are now kept by the world's id, so two worlds with the same name no longer share them (your existing contracts carry over).

The sign on the board now reads BOUNTIES in gold carved letters (the old marks sat too close to the board and partly disappeared). Restart the game to see it on boards already built.

The on-screen tracker is easier to read: taller progress bars with a larger, outlined 3/6, bigger text and more room between contracts.
